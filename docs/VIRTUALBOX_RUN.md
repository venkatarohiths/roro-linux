# VirtualBox Run Guide

## Current status
- VM scaffold can be created from available artifacts.
- For reliable VirtualBox boot, prefer ISO artifact generated by Buildroot CI.

## Steps
1. Build (CI or local) and ensure `rootfs.iso` exists in `out/x86_64-tiny/images/`.
2. Create VM with helper script:
```powershell
powershell -ExecutionPolicy Bypass -File scripts/create-virtualbox-vm.ps1 -IsoPath "out/ci-artifacts/out/x86_64-tiny/images/rootfs.iso"
```
3. Start VM from VirtualBox UI.

## Notes
- If only ext4/rootfs images exist and no ISO/bootloader is present, VirtualBox may not boot.
- In that case, generate ISO-enabled artifacts via CI/local Buildroot and retry.
